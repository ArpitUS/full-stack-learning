# Learning Roadmap

The [66-module catalog](MODULES.md) is the source of truth for module scope, practical deliverables, and mapped workspaces. Follow the dependency-oriented [learning sequence](LEARNING_SEQUENCE.md), then use the templates to turn a module into observable learning evidence.

## How to Use This Section

1. Choose the next module from `MODULES.md` after meeting its prerequisites.
2. Use [MODULE_WORKFLOW.md](templates/MODULE_WORKFLOW.md) to create a learner record, plan work, and select the artifact location.
3. Use [WEEKLY_TRACKER.md](templates/WEEKLY_TRACKER.md) for the active week only.
4. Build the module deliverable in its mapped technology workspace.
5. Record personal evidence under `15-learners/<name>/`, then update TeamOps if the work is shared.

## Progression Map

```text
Git and Linux
    -> Go fundamentals and concurrency
    -> HTTP, REST, architecture, and testing
    -> PostgreSQL and Redis
    -> React and TypeScript client
    -> Authentication and secure integration
    -> Docker and repeatable local stack
    -> CI/CD and AWS deployment
    -> Terraform and Kubernetes
    -> Observability, performance, debugging, and system design
```

See [CROSS_TECHNOLOGY_MAP.md](CROSS_TECHNOLOGY_MAP.md) for technology dependencies and TeamOps integration points.
