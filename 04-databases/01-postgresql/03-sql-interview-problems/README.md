# Module 18: SQL Interview Problems

Practice query reasoning with the schema created in Modules 16-17. This module builds explanation skills, not isolated puzzle memorization.

## Practice Deliverable

Document solutions for duplicates, second-highest values, top N per group, group-wise maximum, running totals, ranking, keyset pagination, and query optimization scenarios. For each solution, state assumptions, SQL, expected result, complexity/scale concern, and an alternative approach.

## Completion Criteria

- [ ] Explain the choice of join, aggregate, window function, or subquery.
- [ ] Identify the data edge cases for each query.
- [ ] Use `EXPLAIN` for at least one query before guessing about performance.
- [ ] Solve the query against actual seeded data.

## Common Mistakes

Ignoring ties, no deterministic order, incorrect `NULL` handling, `NOT IN` with nullable values, and assuming a logically correct query is performant.
