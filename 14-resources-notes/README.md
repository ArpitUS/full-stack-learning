# Resources and Notes

This is the shared reference library, not a duplicate of personal learner notes or the central module curriculum.

## What Belongs Here

- Curated documentation and official references in `01-documentation/`.
- Courses and learning paths in `02-courses/`.
- Articles, videos, and talks in `03-articles-videos/`.
- Cross-topic reusable notes, diagrams, checklists, and decision records in `04-personal-notes/`.
- The supporting [Python module](05-python-secondary-skill/) for module 61.

## Resource Entry Format

When adding a resource, include its title, URL, relevant module number, why it is useful, and a one-line takeaway after using it. Keep personal reflections in each learner's `notes/` folder.

## Completion Evidence

A resource is useful only when it supports a module artifact, TeamOps decision, or a concise shared reference. Prefer official documentation for implementation decisions and record the version/date when behavior may change.
