# Shared Resource Catalog

## Entry Rules

- Include a stable URL, author/publisher when known, and relevant module number(s).
- Add a one-line practical takeaway only after using the resource.
- Record version/date for material that may change, especially cloud, security, Kubernetes, and framework references.
- Do not paste proprietary course material, credentials, or copied private notes.
- Move a broadly reusable diagram/checklist to `04-personal-notes/`; keep individual reflections in learner folders.
