# Module 61: Python Secondary Skill

Python is a supporting skill in this workspace, not a replacement for the primary Go and React path.

## Topics

- Core Python: collections, iterators, generators, decorators, context managers, exceptions, and classes.
- Web and data: FastAPI, Pydantic, `asyncio`, API integrations, pandas, and ETL.
- Engineering trade-offs: Go versus Python for performance, concurrency, types, development speed, and ecosystem.

## Practice

Build one small typed FastAPI utility or an ETL script that consumes a TeamOps-compatible API. Keep the scope narrow and document why Python is the appropriate tool for the task.

## Done When

- [ ] The project has an isolated environment and pinned dependencies.
- [ ] Inputs are validated with types.
- [ ] Automated tests cover a success and failure path.
- [ ] The README documents the Go-versus-Python decision.
