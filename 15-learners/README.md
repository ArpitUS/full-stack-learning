# Learners

This folder supports multiple learners using one shared full-stack workspace. The [66 modules](../01-learning-roadmap/MODULES.md) are the single curriculum source of truth; they are not duplicated per learner.

Arpit and Ashish follow the same curriculum independently and can move at different speeds or focus on different modules. Each learner owns their progress, plans, logs, notes, practice record, and retrospectives.

Put collaborative application work in the shared [projects](../12-projects/) area, especially [TeamOps](../12-projects/teamops/). Keep shared references in [resources and notes](../14-resources-notes/).

## Learner Workflow

1. Select the next module from the shared [catalog](../01-learning-roadmap/MODULES.md).
2. Follow the shared [module workflow](../01-learning-roadmap/templates/MODULE_WORKFLOW.md) and create a module record only when starting it.
3. Plan the week, complete the mapped exercise or deliverable, and record daily evidence.
4. Update personal progress, skills, notes, and practice records.
5. When work improves the product, open a focused TeamOps contribution and update the shared tracker after review.

Individual folders are the source of truth for learner progress. The [dashboard overview](../00-dashboard/LEARNER_OVERVIEW.md) is a manual summary only.

## Shared Templates

Copy the appropriate template into your own learner directory, then rename it for the active work. Do not edit the templates for personal records.

- [Module record](templates/MODULE_RECORD.md) -> `module-progress/module-NN.md`
- [Daily log](templates/DAILY_LOG.md) -> `daily-log/YYYY-MM-DD.md`
- [Practice record](templates/PRACTICE_RECORD.md) -> `practice/YYYY-MM-DD-short-title.md`
- [Retrospective](templates/RETROSPECTIVE.md) -> `retrospectives/YYYY-MM.md` or a milestone name

This keeps learner records consistent while avoiding duplicate curriculum content and merge conflicts.
