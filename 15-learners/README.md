# Learners

This folder supports multiple learners using one shared full-stack workspace. The [66 modules](../01-learning-roadmap/MODULES.md) are the single curriculum source of truth; they are not duplicated per learner.

Arpit and Ashish follow the same curriculum independently and can move at different speeds or focus on different modules. Each learner owns their progress, plans, logs, notes, practice record, and retrospectives.

Put collaborative application work in the shared [projects](../12-projects/) area, especially [TeamOps](../12-projects/teamops/). Keep shared references in [resources and notes](../14-resources-notes/).
