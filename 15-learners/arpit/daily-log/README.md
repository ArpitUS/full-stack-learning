# Daily Logs

Create daily files only when needed, using `YYYY-MM-DD.md`, for example `2026-08-28.md`.

Copy the shared [daily log template](../../templates/DAILY_LOG.md) before starting a new entry.

## Template

```md
# YYYY-MM-DD

- Planned focus:
- What I studied:
- Concepts learned:
- Practice completed:
- Problems / blockers:
- Time spent:
- Notes:
- Next step:
```
