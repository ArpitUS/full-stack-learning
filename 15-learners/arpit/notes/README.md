# Personal Notes

Keep concise personal notes here without duplicating shared curriculum or shared resources. Useful categories are `go/`, `databases/`, `frontend/`, `devops/`, `cloud/`, `security/`, `system-design/`, and `interview-prep/`. Create a category when you first add a note.

Focus on key concepts, your own understanding, mistakes, code examples, and important references. Shared reference material belongs in [resources and notes](../../../14-resources-notes/).
