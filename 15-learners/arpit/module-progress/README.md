# Module Progress

The shared [66-module catalog](../../../01-learning-roadmap/MODULES.md) is the source of truth. Create an individual record when starting a module, named `module-01.md` through `module-66.md`. Do not create all records in advance.

Follow the shared [module workflow](../../../01-learning-roadmap/templates/MODULE_WORKFLOW.md) before marking a module complete. Link the mapped exercise, TeamOps task, pull request, or commit in the record as completion evidence.

Allowed status values: `Not Started`, `In Progress`, `Blocked`, `Completed`, `Review Needed`.

## Template

The maintained shared version is [MODULE_RECORD.md](../../templates/MODULE_RECORD.md). Copy it into this directory as `module-NN.md` before filling it out.

```md

- Learning phase:
- Start date:

- Completion date:

- Challenges:
- Notes:

- Next action:
```
