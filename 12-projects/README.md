# Projects

Projects are the shared integration environment for the curriculum, not a disconnected final exercise. [TeamOps](teamops/) progressively reuses validated work from the technology sections.

## Working Model

1. Learn and test a concept in its mapped module workspace.
2. Propose a focused TeamOps task that applies it to a product need.
3. Implement it in a branch with tests and documentation.
4. Record the contribution and update the relevant TeamOps stage/feature status.

See [TeamOps stages](teamops/STAGES.md) for the staged build plan and [contribution tracking](teamops/CONTRIBUTIONS.md) for shared work.
